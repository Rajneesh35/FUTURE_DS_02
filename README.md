#Facebook Ads Performance Analysis

2 - SHORT DISCRIPTION AND PURPOSE:

This dashboard provides a clear and interactive view of Facebook Ads performance, showcasing key metrics like impressions, reach, clicks, engagement, spend, and ROI ,
Its purpose is to help marketers quickly understand which ads performed best, how efficiently the budget was used, and what improvements can boost future campaign results.

3 - List the key technologies used to build the dashboard:


🔧 Key Technologies Used:

Power BI Desktop – for data modeling, DAX calculations, and dashboard creation

Power Query – for data cleaning, transformation, and preprocessing

DAX (Data Analysis Expressions) – for calculated measures and KPIs

Microsoft Excel / CSV – as the source data format

Power BI Visualizations – for charts, tables, KPIs, and interactive filters


4 - Data Sourcs:
KAGGLE - https://www.kaggle.com/datasets/madislemsalu/facebook-ad-campaign


5 - ⭐ Features & Highlights

• Interactive Dashboard Design – Users can explore campaign performance through dynamic filters, slicers, and drill-down views.
• Comprehensive KPI Tracking – Displays key metrics including CTR, CPC, CPM, Engagement, Spend, and ROI in one place.
• Ad-Level Performance Comparison – Highlights top-performing ads and identifies underperformers with detailed metrics.
• Visual Trend Analysis – Tracks impressions, clicks, and engagement trends over time for deeper insights.
• Budget & ROI Insights – Helps understand spend efficiency and profitability across different campaigns and ad groups.
